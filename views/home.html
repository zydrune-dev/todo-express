Todo

The starting point for a bigger todo app. A small, deliberately simple prototype that saves your todos to localStorage.

This little project exists to practice:

  • Route handling with express.Router and modular route files.
  • Distinguishing / from "not found": when to reach for app.get("/") vs. app.use("/").
  • Serving static JS and CSS via express.static.
  • Having fun re-remembering how to write plain, vanilla JavaScript.
