Todo

A small Express learning app with a growing MVC structure. Todos are saved on the server in data/todos.json; the list page loads them via a JSON API and keeps a localStorage copy for snappy, optimistic UI updates.

This little project exists to practice:

  • MVC layout: routes, controllers, models, and static HTML views.
  • Route handling with express.Router, including nested API routes.
  • Server-side persistence with a JSON file and fs/promises.
  • Form POSTs and JSON APIs (express.urlencoded, express.json).
  • Client-side fetch + localStorage for optimistic list updates.
  • Serving static JS and CSS via express.static.
